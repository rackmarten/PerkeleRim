# skyrim-data

Skyrim plugin data: the ESP (garage near Whiterun, spawn point) and Papyrus scripts. Only original content goes here, never extracted game assets.

`PerkeleRim.esp` isn't stored here: it is generated from your own `Skyrim.esm` by `tools/esp-gen` (see [tools/README.md](../tools/README.md#garage-esp)) with `scripts/build-esp.ps1 [-Deploy]`, into `tools/out/esp/`. Papyrus scripts will live here once there are any.
