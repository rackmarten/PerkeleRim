# Security policy

PerkeleRim is a game mod that runs locally and doesn't talk to the network. Still, it loads native code into Skyrim and managed code into My Summer Car, so a bug could crash a game or corrupt a save.

## Reporting a vulnerability

If you find something that could harm users (for example, a way for a crafted save or file to run code), please **don't open a public issue**. Report it privately through [GitHub's private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability) on this repository.

You'll get a reply as soon as possible. This is a hobby project maintained in spare time, so please allow a few days.

## Supported versions

Only the latest release is supported.
